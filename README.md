# RoadChron-Data

Static signed price dataset for RoadChron. This is not a live API or a proxy. No driver, game, device or location data is collected by the collector. See the RoadChron source package setup guide before publishing. The workflow uses read-only repository permissions and a separate Pages deployment job; it cannot push source changes. Only the repository owner should have write access. It runs daily at 04:17 UTC (GitHub may delay scheduled jobs), and manually via workflow_dispatch. Only enable it once the owner accepts the documented source reuse terms and GitHub hosting terms.

`public/fuel-prices.json` is an envelope containing a base64-encoded UTF-8 JSON payload and a P-256 ECDSA SHA-256 signature (64-byte IEEE P1363). All timestamps are UTC except local publication dates supplied by the price providers. Sources are the approved EIA, EU EnergyPrices, MITECO and ECB feeds; see public/SOURCES.md. DEF is empty until an approved source is available. Regional fuel estimates carry per-grade Estimated flags; source URLs are metadata, not instructions to fetch. Direct prices and estimates remain separate. An unavailable source is not marked fresh merely because the overall dataset was republished. A previous signed dataset is loaded from the configured Pages endpoint; the first publication may return HTTP 404. The workflow leaves the previous deployment intact if collection fails. No private signing key may be committed.

Owner setup: Settings > Pages > Source: GitHub Actions. Under Settings > Secrets and variables > Actions, create repository secret `ROADCHRON_PRICE_SIGNING_KEY` (private PEM) and variable `ROADCHRON_PUBLISH_ENABLED` with value `true` only when ready. Run the workflow from the default branch. Enable 2FA and do not invite write collaborators or install apps with unnecessary write permissions. Public visitors may read or fork, but cannot change this repository. Review and pin third-party workflow action versions before production. The public configuration contains only the URL and public verification key. Keep an offline backup of the private key outside the repository. If the signing key is compromised, disable the workflow, rotate the key and release a newly configured RoadChron build; do not trust an old key.
